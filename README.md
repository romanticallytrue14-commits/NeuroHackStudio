# NeuroHack Studio 4.2

Локальная студия для создания вертикальных VK-клипов: сценарий, озвучка Piper, материалы, музыка и сборка видео через FFmpeg.

## Возможности

- Генерация сценариев, заголовков, описаний и идей офлайн.
- Создание клипа 720 × 1280, 25 FPS; прогресс по этапам и возможность остановить сборку.
- Автоматические субтитры в видео и экспорт отдельного файла `.srt`.
- Автораспределение материалов или ручное назначение файла каждой сцене.
- Сохранение и загрузка проектов, автокопия незавершённой сессии и восстановление при следующем запуске.
- Библиотека готовых клипов и проектов, предпросмотр трека и сценария.

## Запуск

Запустите `main.py` в Python с Tkinter и Pillow. Для создания видео нужны FFmpeg, Piper, `espeak-ng-data` и модели голосов в папке `voices/`.

Папки `output/`, `projects/` и `music/` создаются рядом с программой. Локальные медиа, проекты и автокопии исключены из Git.

## Скачать Windows-сборку

Открой [последние сборки в GitHub Actions](https://github.com/romanticallytrue14-commits/NeuroHackStudio/actions/workflows/build.yml), выбери самый свежий успешный запуск и скачай артефакт **NeuroHackStudio-4.2**. Распакуй архив и запусти `NeuroHackStudio.exe` из распакованной папки. Артефакты Actions хранятся 90 дней; сборка запускается автоматически при push в `main` и ветки `arena/**`.
